The data

Everything on this site comes from five data files, which you can download below. Together they hold every monthly figure the study has collected since January 2023.

Download the data

traffic_monthly.csv Vehicles per day on each of the nine main roads into downtown, each direction, each month month, corridor, direction, vehicles_per_day …

The files are plain CSV and open in Excel. Months are written YYYY-MM. An empty cell means no figure was reported for that month; it is not a zero.

How each figure is calculated

FigureMethod
TrafficVehicles per day are added up across the nine roads for each month. A quarter is the average of its three months. In + out counts a round trip twice.
VisitsA quarter's visits are the total of its three months. The number of people, visits per person and time spent are monthly averages, because the same person recurs from month to month.
Parking occupancyFor each type of parking — on-street, ramps and surface lots — parked cars are divided by spaces, and the three types are averaged. The quarter is the average of its months, and the headline figure averages the three times of day. A facility that was not counted in a month is left out of that month's figure.
TransitBoardings plus alightings, added up across stops. Stops 1004 and 1011 are the Kalamazoo Transit Center.
ChangesEach quarter is compared with the quarter before it and with the same quarter a year earlier. Only quarters with all three months of data are shown as the latest quarter.

Updating the data

The data is kept in a public GitHub repository. Anyone can view it; people added to the project as collaborators can update it each quarter.

  1. Open the repository. Use the button below to go to the project's GitHub page, and sign in to your GitHub account.
  2. Open the data folder and find the file you want to update, such as traffic_monthly.csv.
  3. Replace or edit the file. To replace it, choose Add file → Upload files in the data folder and drop in the new CSV with exactly the same name. For a small change, open the file and click the pencil icon. Keep the same columns and the YYYY-MM month format.
  4. Save the change. Click Commit changes. The website shows the new figures within a few minutes — no page needs to be edited.

The repository's README has the full instructions, including how to rebuild the files from the study's workbooks each quarter.
